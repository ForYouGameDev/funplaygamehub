# Steps
1. github.com par free account -> New repository (e.g. my-game-hub), Public ya Private.
2. "uploading an existing file" se is folder ki saari files upload karo (.github folder ke saath).
3. Repo ke "Actions" tab me "Build APK and AAB" ~5-8 min me khatam hoga.
4. Run kholo -> neeche "Artifacts" -> MyGameHub-APK-AAB download karo (zip me MyGameHub.apk, MyGameHub.aab, release.keystore).
5. release.keystore ko safe rakho (Play Store updates ke liye zaroori).
